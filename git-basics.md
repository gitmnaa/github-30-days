# Git Basics

## Repository

A repository stores project files and their history.

## Commit

A commit records a change in the repository.

## Branch

A branch provides a separate workspace for changes.

## Pull Request

A pull request proposes changes from one branch
to another branch.

## Merge

A merge combines changes into the target branch.
