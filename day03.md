# Day 3 - GitHub Issues

Today I learned how GitHub Issues can help organize
tasks and track project progress.

## What Is an Issue?

A GitHub Issue can be used to report bugs,
suggest improvements, ask questions, or track tasks.

## Today's Practice

- Created a GitHub Issue
- Added a clear task description
- Added a progress comment
- Documented the learning process

## Why Issues Are Useful

Issues help developers organize work and communicate
about changes without losing track of important tasks.

## Day 3 Reflection

I learned that GitHub is not only a place to store code.
It also provides tools for planning, communication,
and project management.
