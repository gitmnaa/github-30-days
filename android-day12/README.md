# Day 12 - Android Contact List

A simple Android contact list built with Kotlin and XML.

## Features

- Display contacts using RecyclerView
- Custom RecyclerView adapter
- Kotlin data class
- XML layouts
- Clean Android project structure

## Technologies

- Kotlin
- Android
- RecyclerView
- XML
- Gradle

## Concepts

This project demonstrates how Android applications can
display structured data using a RecyclerView and adapter.
